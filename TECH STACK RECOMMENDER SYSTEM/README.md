# Tech Stack Recommender System

An AI-driven recommendation system designed to match specific developer skill sets with their ideal technology stacks utilizing TF-IDF Vectorization and Cosine Similarity.

---

## 📁 Project Structure
* `AI_Project3_Tech stack Recommendation.py` - Core Python backend script.
* `AI_Project3_Tech stack Recommendation.ipynb` - Jupyter Notebook for data exploration.
* `raw_skills.csv` - The underlying skills and technology dataset.
* `requirements_p3.txt` - Project dependencies.
